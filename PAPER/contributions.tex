Prior work established uniformly distributed (UD) CORDIC as a way to remove the
Z-path from a rotation datapath~\cite{garrido2025ud}. Applying it to RoPE,
however, exposes three questions that do not arise for generic rotation, and
that this work answers.

\textbf{The angle encoder is not free, and the obvious one does not work.}
A UD-CORDIC stage rotates by $a_i = \arctan(2^{-(i+1)})$, not by $2^{-(i+1)}$.
Because rotations compose additively, encoding a target angle is a subset-sum
over $\{a_i\}$, and those weights are only approximately geometric:
$a_i / 2^{-(i+1)} = 0.927, 0.980, 0.995, 0.999, \ldots$ Taking the digits
directly from the binary representation of $\theta$ -- the construction implied
by the UD formulation -- therefore mis-encodes the leading stages, and the
resulting angular error is independent of pipeline depth. We show that the
tail is geometric to better than $0.13\%$ and can be read straight off the
residual, so only the two leading stages need explicit resolution. The
resulting encoder is a single adder, three constant comparators, a $4{:}1$
constant multiplexer and one subtractor; it is fully combinational, so the
Z-path-free property is preserved. It achieves $0.094^{\circ}$ RMS angular
error at $N = 10$, against $2.20^{\circ}$ for the direct binary construction.

\textbf{RoPE makes CORDIC gain compensation free, but only for one variant.}
The scale factor $K = \prod_i \sqrt{1 + 2^{-2(i+1)}}$ normally costs a
compensation multiplier. In RoPE it costs nothing: queries and keys traverse
the same rotator, so the attention logit $\langle \mathbf{q}_m, \mathbf{k}_n
\rangle$ is scaled by exactly $K^2$, a position-independent constant that folds
into the existing $1/\sqrt{d_h}$ attention scale. This holds for Binary UD,
whose digits satisfy $\delta_i \in \{-1,+1\}$ and whose gain is therefore
angle-independent ($K = 1.164435$, measured spread $\pm 0.0003$). It does
\emph{not} hold under radix-4 stage merging: a merged stage has gain
$\sqrt{1 + v^2 4^{-i}}$, which depends on the digit magnitude, so any digit set
with more than one magnitude has an angle-dependent gain --- and a
fixed-magnitude set is one bit per stage, which is Binary UD. Constant gain and
stage merging are mutually exclusive. We quantify the consequence
(WikiText-2 perplexity $+908\%$ on LLaMA-2-7B uncompensated) and show that
compensating the leading stage alone, with a three-constant shift-add network
costing <<TBD>>\,$\mu$m$^2$, recovers to within $0.8\%$.

\textbf{The precision requirement is set by the frequency schedule, not the
model size.} Sweeping the fractional width end-to-end across two 7B models
gives requirements that differ by two bits: LLaMA-2-7B is within $0.32\%$ of
its floating-point baseline at $F = 8$, while Qwen2-7B needs $F = 10$ and has
already lost $6.4\%$ at $F = 9$. The cause is the RoPE base --- $10^6$ for
Qwen2 against $10^4$ for LLaMA-2 --- which spreads $\Theta_i$ over a far wider
dynamic range and leaves the low-frequency dimensions with angles too small to
resolve at coarse precision. We also find that a fixed-point RoPE datapath
cannot be deployed as published: measured query and key activations reach
$|q| = 132$ and $|k| = 178$, against the $[-2, 2)$ range of the $Q1.F$ format,
so a shared-exponent normalisation stage is a functional requirement rather
than an optimisation.
